Dein Lernstand

Der äußere Ring zeigt das Ergebnis des Abschlusstests. Der innere Ring zeigt, wie viele der bereits bearbeiteten Übungsaufgaben richtig gelöst wurden.

Äußerer Ring: Abschlusstest Innerer Ring: bearbeitete Übungen

So sicherst du deinen Lernfortschritt

Deine Ergebnisse werden nur in diesem Browser gespeichert. Mit Export kannst du eine Sicherungskopie erstellen und sie später wieder einlesen – auch auf einem anderen Gerät.

Export = Fortschritt sichern

Wähle oben Export. Dein Browser lädt eine kleine JSON-Datei herunter. Bewahre sie an einem Ort auf, an dem du sie später wiederfindest.

Import = Fortschritt wiederherstellen

Wähle oben Import und öffne deine zuvor gesicherte JSON-Datei. Bestätige anschließend, dass die vorhandenen Daten ersetzt werden dürfen.

Wichtig: Eine Exportdatei enthält den Lernfortschritt aus beiden Lernpaketen. Beim Import wird der aktuell gespeicherte Fortschritt vollständig ersetzt.
